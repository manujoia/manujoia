Aplicação de gestão financeira pessoal, projeto acadêmico em equipe. Participei do levantamento de requisitos, das telas no Figma, do front-end e da camada de dados em Java (JDBC e DAO) com Oracle SQL. O repositório inclui as user stories, a modelagem UML e o modelo de dados.
